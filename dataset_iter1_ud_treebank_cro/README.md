## Full Summary

This dataset provides a single joinable metadata table covering all 336 UD treebanks from commul/universal_dependencies. Each row contains: (1) WALS Feature 81A word-order classification (SOV/SVO/VSO/VOS/OVS/OSV/No dominant order) at 61.3% coverage, joined via ISO 639-3 with macrolanguage fallbacks (ara->arb, zho->cmn); (2) Glottolog language family, family ID, and macroarea at 92.6% coverage from glottolog-cldf; (3) morphological case richness (distinct Case= values and token proportion) computed from feats columns via streaming, ranging 0-22 cases; (4) head-direction entropy in binary and per-deprel weighted variants from head columns; (5) curated spoken/written/mixed modality labels (14 spoken, 11 mixed, 311 written) with spoken-written pair IDs verified against configs, based on Dobrovoljc (2022); (6) differential object marking flags for 33 treebanks across 8 language groups; (7) basic stats (num_sentences, num_tokens, mean_sentence_length) and disfluency deprel flags. All fields are null-safe. Compiled using 4-worker parallel processing across all 336 treebanks with zero failures. Output uses exp_sel_data_out.json schema with 336 examples in one dataset group. Word orders found: SVO(126), SOV(51), No dominant(18), VSO(11). Top families: Indo-European(177), Afro-Asiatic(20), Turkic(19), Uralic(16). Macroareas span Eurasia, Africa, South America, North America, Papunesia, and Australia.
