## Full Summary

This experiment processes 870,677 sentences across 335 UD treebanks to compute standard and encounter-only Instantaneous Memory Burden (IMB) profiles, then executes the Phase 1 novelty test by regressing max(IMB) on DD moments and tree properties.

For each sentence, the standard IMB profile accumulates age of each open dependency at every position. The encounter-only variant restricts to head-initial dependencies only. The decomposition identity total_IMB = sum(d_k*(d_k+1)/2) was verified on 32,669 spot-checks with zero failures.

Worked example replication confirmed: two 5-node trees sharing identical DD multisets {1,1,2,2} produce different IMB profiles, max values (3 vs 2), and quadratic costs (18 vs 16), while linear costs are identical, demonstrating IMB captures temporal overlap invisible to DD statistics.

Phase 1 novelty test: Pooled OLS of max(IMB) on 7 predictors yields R²=0.9475 (standard) and R²=0.8827 (encounter-only). Head-type splits (103 head-final, 151 head-initial, 82 mixed) reveal differential patterns. The encounter-only variant falls below the 0.90 novelty threshold, confirming temporal overlap from head-initial dependencies contains genuinely novel signal beyond aggregate DD statistics. All analyses include per-treebank regressions, residual distributions, and descriptive statistics stratified by head type, modality, and word order across all 335 treebanks.
