## Full Summary

This evaluation decomposes R² monotonicity across convexity exponent α into mathematical vs empirical components by comparing real sentences against 50 random projective baselines per sentence across 86 UD treebanks (41,129 sentences). The core analysis computes pooled OLS R² for real and baseline data at each α ∈ {1.0, 1.2, 1.5, 2.0, 3.0} using 6 features (DD moments + tree properties). Key finding: ΔR² increases from -0.04 at α=1.0 to +0.24 at α=3.0 (Spearman ρ=0.9), meaning baseline R² drops faster than real R², ruling out the mathematical artifact hypothesis. Bootstrap 95% CIs (2000 treebank-level resamples) quantify uncertainty. Typological stratification of residualized convexity Cohen's d by word order shows significant Kruskal-Wallis differences at α≥2.0 (p<0.05), but ranking (SVO>SOV>VSO) differs from LLF pattern (VSO>SVO>SOV). Per-treebank R² for all 86 treebanks confirms the gap pattern is consistent. Three verdict metrics: not mathematical artifact (ρ=0.9, range=0.28), not merely weak empirical (max gap=0.24), not typologically modulated in LLF-matching sense. Uses ProcessPoolExecutor with 4 workers, completing in ~9 min. Output conforms to exp_eval_sol_out schema with 80+ aggregate metrics and per-treebank examples with eval_ and predict_ fields.
