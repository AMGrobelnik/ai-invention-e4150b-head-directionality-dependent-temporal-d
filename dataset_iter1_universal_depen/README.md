## Full Summary

This dataset downloads and processes 335 Universal Dependencies (UD) treebanks from commul/universal_dependencies on HuggingFace, extracting syntactic dependency tree features per sentence. Sentences with fewer than 8 non-punctuation tokens are filtered out.

Each example's input contains: raw text, tokens, integer head indices, dependency relations, UPOS tags (converted from int to string), and morphological features. The output provides 17 computed features: sentence_length, effective_length, tree_depth, max_arity, mean_arity, mean_dd (dependency distance), dd_variance, dd_skewness, dd_list, projectivity_proportion, n_nonprojective, mean_ic (intervener complexity), ic_variance, max_ic, functional_ratio, content_ratio, and head_direction_entropy.

Projectivity uses descendant-based arc crossing detection. Head-direction entropy captures left/right dependency balance via Shannon entropy. Intervener complexity counts head nodes between dependent and governor.

Coverage: 335 treebanks across 100+ languages, 870,677 examples from 2,198,185 initial sentences (per-treebank cap: 10,000). Only qte_tect failed to load. Per-example metadata includes fold (train/dev/test), treebank_id, language_code, treebank_name, and sent_id.

Output follows exp_sel_data_out schema. The full output (~1.95 GB) is split into 23 files under 95 MB each. Processing uses memory-safe streaming: each treebank saved to temp file independently, then assembled without holding all data in memory.
